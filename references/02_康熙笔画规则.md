# 康熙字典笔画体系与取数规则

## 一、为什么要用"康熙笔画"

五格剖象法（熊崎氏）成法于日本明治年间，其数理依据是**《康熙字典》所载繁体字形笔画**，原因是：
1. 康熙笔画以**部首本字**计画（如"氵"按"水"4画、"艹"按"艸"6画），保留了造字时的五行属性；
2. 81数理表按康熙笔画编排，采用简体笔画会整体错位，吉凶判断失效；
3. 繁体字形笔画稳定，不受简化方案影响。

**结论：输入可用简体，计算必须按繁体康熙笔画。**

## 二、特殊部首换算表（★ 工程核心）

康熙笔画 = 部首本字笔画 + 剩余部件笔画。以下部首**不能按现代字形笔画数**：

## 三、数据资产说明

### 3.1 文件结构
```json
{
  "_meta": {
    "source": "康熙字典笔画（姓名学通行值）",
    "version": "1.0",
    "char_count": 700,
    "note": "键为常用简体/繁体写法，值为康熙笔画"
  },
  "radical_rules": { "氵": 4, "忄": 4, "艹": 6, "辶": 7, "阝_left": 8, "阝_right": 7 },
  "chars": { "李": 7, "明": 8, "华": 14, "刘": 15 }
}
```

### 3.2 覆盖范围
- **百家姓全部常见姓**（含繁体对应：刘→劉15、张→張11、陈→陳16、杨→楊13、赵→趙14、黄→黃12、吴→吳7、郑→鄭19、罗→羅20、苏→蘇22…）
- **高频取名用字** 600+，覆盖 1–24 画。
- 姓氏若有两读（钟=鍾17/鐘20），取姓名学通行值并在此注明。

### 3.3 缺字处理（三级策略）
| 模式 | 行为 | 适用 |
|---|---|---|
| `strict` | 抛出 `MissingStrokeError`，附缺字清单 | 批量校验、CI |
| `ask`（默认） | 返回缺字清单，提示用户提供笔画或改用他字 | 交互对话 |
| `fallback` | 按 `radical_rules` 部件拆分估算，结果标 `confidence:"low"` 并在报告顶部告警 | 快速试算 |

### 3.4 数据维护接口
```bash
python scripts/stroke_query.py add 玥 9          # 新增/覆盖
python scripts/stroke_query.py add-batch words.txt  # 批量（每行：字 笔画）
python scripts/stroke_query.py stats             # 统计覆盖率
```
写入后自动更新 `_meta.char_count`，并保留 `_history` 审计记录。
