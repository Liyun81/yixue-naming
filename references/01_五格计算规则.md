# 五格剖象法 · 计算规则权威文档

> 版本：v1.0 ｜ 本文件是脚本实现的唯一算法依据。任何与本文冲突的心算结果，一律以本文 + `scripts/wuge.py` 为准。

## 一、术语与数据结构约定

### 1.1 姓名切分（NameSplit）

```
姓名 = 姓（Surname）+ 名（Given name）
姓：S = [s1, s2, ...]，长度 1 或 2（复姓），极少数 3 字姓按复姓扩展规则处理
名：G = [g1, g2, ...]，长度 1（单名）或 2（双名）
```

记 `strokes(x)` = 字符 x 的康熙字典笔画数（查 `assets/kangxi_strokes.json`）。

### 1.2 结构枚举（Structure）

| 代号      | 结构   | 示例           |
| ------- | ---- | ------------ |
| `SS_GG` | 单姓单名 | 王五（王/五）      |
| `SS_GD` | 单姓双名 | 李明华（李/明华）    |
| `DS_SG` | 复姓单名 | 诸葛 亮（诸葛/亮）   |
| `DS_GD` | 复姓双名 | 欧阳 明华（欧阳/明华） |

## 二、五格计算总表（★ 核心算法）

设 `n = strokes`，`S` 为姓序列，`G` 为名序列。

| 格      | 通用公式                      | 单姓单名        | 单姓双名        | 复姓单名        | 复姓双名        |
| ------ | ------------------------- | ----------- | ----------- | ----------- | ----------- |
| **天格** | 单姓：n(s1)+1；复姓：n(s1)+n(s2) | n(姓)+1      | n(姓)+1      | n(姓1)+n(姓2) | n(姓1)+n(姓2) |
| **人格** | n(姓末字) + n(名首字)           | n(姓)+n(名)   | n(姓)+n(名1)  | n(姓2)+n(名)  | n(姓2)+n(名1) |
| **地格** | 双名：n(g1)+n(g2)；单名：n(g1)+1 | n(名)+1      | n(名1)+n(名2) | n(名)+1      | n(名1)+n(名2) |
| **外格** | **边缘字之和 + (2 − 边缘字数)**    | **2**（默认流派） | n(名2)+1     | n(姓1)+1     | n(姓1)+n(名2) |
| **总格** | 全名所有字笔画之和                 | 全名和         | 全名和         | 全名和         | 全名和         |

> **边缘字** = 姓中除末字的部分 + 名中除首字的部分（其余字已被人格、地格占用）。  
> 外格须恒由「两数」构成，故不足时以虚数 1 补足，四字全备时不再补。四种结构由此自然收敛为传统取值，无需分情况硬编码。

### 2.1 外格流派分歧点

- **主流虚数派（本技能默认）**：按上式，单姓单名外格 = **2**。  
  学理依据：单姓单名边缘字为 0 个，须补两个虚数（天格虚 1、地格虚 1），故外格为 2。
- **数理自洽派**：坚持单一公式 `总格 − 人格 + 1`，单姓单名则取 **1**。  
  学理依据：不接受"虚数补位"的解释，只求公式统一。**注意：此式仅当边缘字数为 1 时与主流派等值，复姓双名会多出 1，不可通用。**
- **工程处理**：`WugeConfig.waige_mode ∈ {"virtual_2"（默认）, "formula_1"}`，CLI 用 `--waige-mode` 切换，报告须注明所采用流派。

### 2.2 天格/地格"加 1"的学理

天格、地格本为"天地之数"，单字无法成格局（孤阴不生），故虚设一数以成阴阳对待之势。复姓、双名已具两数，不再虚加。

## 三、数理与五行

### 3.1 数理归约

```
def to_number(v:int) -> int:     # v 为各格笔画和
    if v <= 0: raise ValueError
    r = v % 81
    return 81 if r == 0 else r
```

例：总格 82 → 数理 1；总格 81 → 数理 81。

### 3.2 五行归属（按格数尾数）

```
尾数 1,2 → 木；3,4 → 火；5,6 → 土；7,8 → 金；9,0 → 水
```

注：尾数 0 视作 10，属**水**（如人格 20、30 均以水论）。三才五行取的是**各格原始数值**的尾数，不是数理的尾数。

### 3.3 五行生克

- 相生：木→火→土→金→水→木
- 相克：木→土→水→火→金→木
- 关系函数：`relation(a, b)` ∈ {同(比和), 生(我生/生我), 克(我克/克我)}

## 四、完整算法流程（工程伪代码）

```
INPUT: surname(字符串), given(字符串), config
STEP 1  输入校验
        1.1 非空、长度 2~6 字
        1.2 全为 Unicode CJK 汉字（含扩展区），非汉字→抛 InvalidNameError
        1.3 姓长 1~2，名长 1~2（超出走 extended 规则并告警）
STEP 2  切分与结构判定 → structure
STEP 3  笔画查表
        for ch in 全名: strokes[ch] = query(ch)
        缺失→收集 MissingStrokeError，按 config.on_missing 处理
        （策略：strict=抛错 / ask=返回待补列表 / fallback=部首推算并标记 low_confidence）
STEP 4  按第二节总表计算五格原始值
STEP 5  数理归约 to_number → 查 eighty_one_numbers.json 得吉凶与释义
STEP 6  五行：天/人/地三格尾数 → 三才五行三元组 (T,R,D)
STEP 7  三才分析 → 查 sancai_config.json（125 条）：
        7.1 关系判定：天↔人（成功运）、人↔地（基础运）
        7.2 取 judgement（大吉/吉/半吉/凶/大凶）+ 影响文案
STEP 8  评分
        base = Σ(各格数理分 × 权重) × 三才修正系数
        bonus = 特殊数理标签加分（财富数/首领数/艺能数等）
        penalty = 凶数（尤其人格/总格大凶）扣分
        score = clamp(0,100, round(base + bonus - penalty))
        等级：≥90极佳 ≥80优秀 ≥70良好 ≥60一般 ≥50平平 <50欠佳
STEP 9  多维度解读（性格/事业/财运/健康/婚姻/家庭）
        按 references/04 第六章模板生成
STEP 10 输出 NameReport（JSON + 文本报告），附免责声明
```

## 五、边界规则与异常处理

### 5.1 异常类型

| 异常                      | 触发条件              | 处理                                             |
| ----------------------- | ----------------- | ---------------------------------------------- |
| `InvalidNameError`      | 空值、含非汉字、长度越界      | 返回明确提示 + 期望格式                                  |
| `MissingStrokeError`    | 笔画表缺字             | strict 抛错 / ask 返回缺字清单 / fallback 部首法估算（标记置信度） |
| `AmbiguousSurnameError` | 无法判定单姓/复姓（如"欧阳光"） | 询问用户，或两种结构都算并对比                                |
| `WugeComputeError`      | 计算中出现非正数等非法值      | 中止并回传上下文                                       |

### 5.2 特殊场景

1. **单名**：地格 = 名笔画+1，外格按特例；单名在五格法中先天偏弱（地格虚数），报告中宜提示。
2. **复姓**：见附录常见复姓表；不在表内但用户确认的，按 DS 规则计算。
3. **三名以上/少数民族长名**：超出五格法适用范围，`--extended` 按"名全部相加为地格、外格=总格−人格+1"近似处理并显著告警。
4. **叠字名**（如 婷婷）：照常按双名计算，无特殊规则；报告中可提示"重字格局主静"。
5. **性别**：影响部分数理的解读（首领数 21/23/33/39 女性用传统认为婚姻不利），`--gender` 参数传入，未传时解读中性化。
