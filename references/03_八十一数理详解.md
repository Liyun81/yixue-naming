## 一、数理渊源

八十一数理取「九九还元」之义：9 × 9 = 81，数尽而复始。传统以 1–81 为宇宙万有之数序，每一数配以象名与吉凶，构成姓名学判断吉凶的基本单位。

五格剖象法将五格笔画和归入 81 数理：

```
数理 = 格数 % 81，若余 0 则记 81
例：总格 82 → 数理 1；总格 81 → 数理 81；总格 162 → 数理 81
```

> **不要**把 81 数理与五行混为一谈：五行取**格数尾数**，数理取**模 81 的余数**，二者是两套独立标尺。

## 七、使用约定

1. 报告中每格都必须给出「格数 → 数理 → 象名 → 吉凶 → 五行」五要素，缺一不可。
2. 数理释义引用 `summary`（一句总论）；深度解读引用 `detail`。
3. `poem` 字段为传统诗诀，可在报告中作为点缀引用，不宜作为结论。
4. `health` 字段仅作温和提示，**原文已做去恐吓化处理**，引用时不得加码。
5. 数理凶而三才吉时，判断应倾向"阻而有救"，反之亦然——数理与三才必须合参。
