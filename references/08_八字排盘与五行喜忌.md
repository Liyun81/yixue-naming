# 八字排盘与五行喜忌（真太阳时口径）

> ⚠️ 定位声明：八字排盘与喜忌分析属于传统子平命理范畴，仅供民俗文化参考，
> 不具备科学预测效力，不构成人生决策依据。本文件是技能的**口径与规则说明**，
> 排盘一律由 `scripts/bazi.py` 计算，不心算、不臆断。

## 一、真太阳时

### 1.1 为什么需要真太阳时

八字时辰按**当地真太阳时**划分（古代用日晷，即视太阳时）。中国统一使用北京时间
（东经 120° 平太阳时），出生地若远离 120°E，地方平时与北京时有显著差异：
每差 1° 经度，时差 4 分钟。成都（104.07°E）比 120°E 慢约 64 分钟——同一个
"15:00"，在北京真太阳时约为 14:46（申时），在成都约为 13:56（**未时**）。
不校正会把时辰排错，进而时柱、甚至日柱（跨 23:00 时）全错。

### 1.2 时区换算与夏令时还原

出生时间按**出生地当地时间**输入，换算链路为：

```
当地墙上时间 ──(--tz)──▶ 北京墙上时间 ──(夏令时还原)──▶ 北京标准时间
                                                            │
                              均时差 EoT + 经度修正 ◀────────┘
                                    │
                                    ▼
                                真太阳时
```

- **时区（`--tz`）**：默认按北京时间（UTC+8）解释；境外出生给时区偏移
  （如美西 `--tz -8`、印度 `--tz +5:30`），换算为北京时间后再进入后续步骤。
  境外时区的夏令时由用户在偏移中自行体现，不再套用中国夏令时。
- **夏令时还原（1986–1991）**：1986–1991 年全国实行夏令时，每年 4 月中旬
  第一个星期日 02:00（标准时）拨快至 03:00，9 月中旬第一个星期日 02:00
  （夏令时）拨回至 01:00（1986 年为 5/4–9/14）。**期间出生的记录时间须
  减 1 小时**才是标准时间。默认自动还原（`--no-dst` 可关闭）。边界口径：
  - 开始日 02:00–02:59 墙上时间被拨快跳过，不存在，按标准时解释；
  - 结束日 01:00–01:59 为重复时刻，按标准时解释；00:00–00:59 仍是夏令时；
  - 还原可能跨至前一日 23 时。
- 还原后的标准时间同时用于**年柱、月柱**的节气判定——夏令时年份出生在节气
  交接当日的人，月柱/年柱判定同样受影响（如 1990-05-06 02:40 还原为 01:40，
  在立夏 02:35:26 之前，月柱仍属辰月）。

### 1.3 计算式

```
真太阳时 = 北京标准时间 + 均时差 EoT + (出生地经度 − 120°) × 4 分钟
```

- **经度修正**：`(λ − 120°) × 4`，λ 为出生地东经。成都 = −63.7 分钟
  （西经地方时慢，真太阳时数值上**更早**）；哈尔滨（126.64°E）= +26.6 分钟
  （东经地方时快，真太阳时数值上**更晚**）。
- **均时差 EoT**（真太阳时与平太阳时之差，由地球公转椭圆与黄赤交角引起，
  一年内在 −14.2 ~ +16.4 分钟之间波动，约 2/11 最小、11/3 最大，4/15、6/13、
  9/1、12/25 前后为零）：采用 Meeus《Astronomical Algorithms》太阳视位置
  算法（NOAA 太阳计算器同源，由平黄经/平近点角求真黄经与视赤经，
  EoT = 4×(L0 − 视赤经)），在出生时刻评估，**误差 < 0.1 分钟**；
  输出截断到分（不四舍五入，避免把 HH:59:50 抬进下一时辰）。
- 出生地经度取自内置城市表（67 处，含省会和主要地级市，港澳台按全称显示），
  未收录城市用 `--longitude` 直给；未提供出生地按东经 120°（无经度修正）。
- 校正后可能跨时辰、跨日；日柱、时柱一律以校正后的真太阳时为准。

### 1.4 柱别口径（重要）

| 柱别 | 判定基准 | 说明 |
|---|---|---|
| 年柱 | 北京标准时间 + 标准节气表 | 以立春交接时刻为界，**不是农历春节** |
| 月柱 | 北京标准时间 + 标准节气表 | 以十二节为界，节气交接**时刻**精确到分秒 |
| 日柱 | **真太阳时** | 儒略日（JDN）自算；晚子时（真太阳时 23:00–24:00）算次日 |
| 时柱 | **真太阳时** | 五鼠遁推时干；时辰按真太阳时的两小时划分 |

说明：节气交接时刻表本身是东八区标准时（北京时间）。出生与节气交接同日时，
真太阳时化对年月柱判定没有影响；主流排盘软件（问真八字等）同样采用
"节气按标准时、时辰按真太阳时"的双轨口径。节气交接与出生**不同日**的罕见
情形，本技能按上表执行。年/月柱判定用的标准时间已含时区换算与夏令时还原
（见 1.2）。

### 1.5 晚子时

真太阳时 23:00–24:00 出生：**日柱、时柱均算次日**（主流八字派口径）。
例：2024-06-21 23:30（北京）→ 真太阳时 23:13 → 日柱取 06-22（丁巳），
时柱为丁日子时（庚子）。夏令时年份的 23:30 会先被还原为 22:30，是否进
晚子时以还原后的真太阳时为准。

时辰未知（用户只给日期）：以正午定年月日三柱，时柱从略；报告中明确标注，
喜忌分析以三柱为据。

## 二、四柱与历法内核

- **节气精确时刻**：内置历法内核 `scripts/vendor/lunar_python`（lunar-python
  1.4.8，MIT 许可，见 `scripts/vendor/NOTICE.md`），寿星天文历算法，时刻精度到秒，
  返回北京时间。随技能分发，运行零第三方依赖；升级内核须重跑回归测试
  （tests.py 内置 300 组年/月/日/时柱交叉验证，PyPI 版未安装时与 vendor 版比对）。
- **年柱**：立春（太阳黄经 315°）交接时刻为界。立春前出生属上一干支年。
- **月柱**：十二节（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、
  立冬、大雪、小寒）为界；月干按年干五虎遁推导（甲己之年丙作首）。
- **日柱**：儒略日数推干支（JDN mod 60 映射，自算并与历法内核交叉验证一致；
  公开锚点 1949-10-01 = 甲子、2000-01-01 = 戊午、2024-01-01 = 甲子）。
- **时柱**：日干五鼠遁（甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，
  戊癸何方发，壬子是真途），时支按真太阳时两小时分段（23–1 点子、1–3 丑……）。

## 三、五行力量统计

| 要素 | 权重 |
|---|---|
| 天干（四字，含日主自身） | 各 1.0 |
| 地支藏干 | 本气 1.0 / 中气 0.6 / 余气 0.4 |
| 月令地支（当权） | 藏干权重合计 × 1.5 |

地支藏干表（本气、中气、余气）：

| 支 | 藏干 | 支 | 藏干 |
|---|---|---|---|
| 子 | 癸 | 午 | 丁、己 |
| 丑 | 己、癸、辛 | 未 | 己、丁、乙 |
| 寅 | 甲、丙、戊 | 申 | 庚、壬、戊 |
| 卯 | 乙 | 酉 | 辛 |
| 辰 | 戊、乙、癸 | 戌 | 戊、辛、丁 |
| 巳 | 丙、戊、庚 | 亥 | 壬、甲 |

十神按日干五行判：同我=比劫、我生=食伤、我克=财、克我=官杀、生我=印。

## 四、日主强弱

```
生助力 = Σ(比劫 + 印)    克泄力 = Σ(食伤 + 财 + 官杀)
强弱比 = 生助 / (生助 + 克泄)
```

| 强弱比 | 判定 |
|---|---|
| ≥ 0.62 | 身强 |
| 0.54–0.62 | 中和偏强 |
| 0.46–0.54 | 中和 |
| 0.38–0.46 | 中和偏弱 |
| < 0.38 | 身弱 |

三项佐证（写入报告）：
- **得令**：月令对日主为旺或相（月令旺相休囚死：当令旺、所生相、生者休、
  克者囚、所克死）；
- **得地**：四支藏干中有日主同五行（有根）；
- **得势**：天干中比劫/印 ≥ 2 个。

## 五、喜忌推导

| 格局 | 喜（用神/喜神候选） | 忌 |
|---|---|---|
| 身强 / 中和偏强 | 财、官杀、食伤（克泄耗） | 印、比劫（生扶） |
| 身弱 / 中和偏弱 | 印、比劫（生扶） | 财、官杀、食伤 |
| 中和 | 缺者补之（最弱五行为喜） | 旺者泄之（最旺五行为忌） |

- **用神**：喜类中力量最弱者（最需补）；**喜神**：其余喜类；
  **忌神**：忌类中力量最旺者；**仇神**：生忌神之五行；**闲神**：其余。
- **调候**（附加修正，仅在该行偏枯时生效）：
  - 生于巳午未月且水 < 1.5 → 水升为喜类（火炎土燥，调候以水为急）；
  - 生于亥子丑月且火 < 1.5 → 火升为喜类（水冷金寒，调候以火为急）。

## 六、原盘评分

```
均衡分 = 五行占比方差 → 平衡度（0–1）→ ×88
        − 缺行数 × 5  + 通关链（四行以上俱全 +4）
```
取值 30–95；≥80 流通、≥70 偏衡、≥60 中平、余偏枯。仅描述原盘结构，
**不并入姓名综合分**（八字是命理维度，与姓名维度各自独立）。

## 七、边界与禁忌

- 排盘需要出生时间与出生地；时辰未知可只给日期（时柱从略，报告注明）。
- 报告必须包含排盘口径（真太阳时公式与柱别基准），供用户核对。
- 不据八字断疾病、断寿夭、断婚变；不出"改运""化解"式表述。
- 免责声明（仅供审美与文化参考，不具备科学预测效力）在报告八字段与
  八字图内均为固定元素，不可省略。
