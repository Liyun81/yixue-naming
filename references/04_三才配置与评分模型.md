# 三才配置、评分模型与解读模板

## 第一章 三才的构成

**三才**指天、人、地三个格位的五行组合：

| 位 | 取数 | 象征 | 主管 |
|---|---|---|---|
| 天才 | 天格 | 祖上、长辈、上级、先天环境 | 成功运（能否得势） |
| 人才 | 人格 | 自身、核心性格、主运 | 命运主轴 |
| 地才 | 地格 | 基础、家庭、下属、晚辈 | 基础运（根基是否稳固） |

三才组合共 `5×5×5 = 125` 种，记作「天木人火地土」形式，简写五行序如 `木火土`。

### 1.1 五行取数规则（★ 易错）

五行按**格数原始值的个位数**判定，**不是**数理（1–81）的个位数：

```
尾数 1,2 → 木
尾数 3,4 → 火
尾数 5,6 → 土
尾数 7,8 → 金
尾数 9,0 → 水   （0 视作 10）
```

例：人格 12 → 尾数 2 → 木；人格 20 → 尾数 0 → 水；人格 31 → 尾数 1 → 木。

> 注意：若先对 81 取模再取尾数，结果相同（因 81 的尾数为 1，会错位）。**必须用原始格数取尾数。**

## 第二章 生克关系与判断逻辑

### 2.1 五行生克
- 相生：木→火→土→金→水→木
- 相克：木→土→水→火→金→木
- 比和：同气相求

### 2.2 成功运（天格 ↔ 人格）

| 关系 | 术语 | 分值 | 传统判语 |
|---|---|---|---|
| 天生人 | 天格生人格 | 100 | 得长辈、上级提携，事顺而贵人多，易成功 |
| 天人比和 | 同气 | 88 | 与上和谐，稳步而进，无大起落 |
| 人克天 | 人格克天格 | 72 | 不甘受制，能自立突破，然与上级多摩擦，劳心而成 |
| 人生天 | 人格生天格 | 62 | 付出多而得助少，为家庭长辈操劳，成事较缓 |
| 天克人 | 天格克人格 | 40 | 受压制、多阻碍，须借地格与他力化解 |

### 2.3 基础运（人格 ↔ 地格）

| 关系 | 术语 | 分值 | 传统判语 |
|---|---|---|---|
| 地生人 | 地格生人格 | 100 | 根基稳固，得家庭、下属支持，安如磐石 |
| 人地比和 | 同气 | 90 | 内外一致，安稳平顺 |
| 人克地 | 人格克地格 | 86 | 能掌控局面与部属，主动而不失稳 |
| 人生地 | 人格生地格 | 64 | 为家庭、子女付出多，自身耗损 |
| 地克人 | 地格克人格 | 42 | 根基不稳，家庭或下属易生牵累 |

### 2.4 三才综合
```
三才分 = 成功运分 × 0.5 + 基础运分 × 0.5
等级：≥90 大吉 ｜ ≥80 吉 ｜ ≥68 半吉 ｜ ≥52 凶 ｜ <52 大凶
```
> 流派说明：另有"以人格为中心、天格地格并看"的加权法（天 0.3 / 地 0.7），本技能默认前后各半，可在 `WugeConfig.sancai_weight` 调整。

## 第三章 评分模型

### 3.1 权重（默认，可配置）

| 项 | 权重 | 理由 |
|---|---|---|
| 人格数理 | 30% | 主运，核心 |
| 地格数理 | 18% | 前运与基础 |
| 总格数理 | 20% | 一生总论、后运 |
| 外格数理 | 8% | 副运、社交 |
| 天格数理 | 4% | 祖运，先天不可改，权重最低 |
| 三才配置 | 20% | 五行格局，决定成败大势 |

合计 100%。**天格在传统上"不论吉凶"**（祖上既定，非本人可为），故仅给 4%，且其数理为凶时不作强扣分，仅提示。

> 注：天格在单姓时为「姓笔画+1」的虚数，本身不具吉凶意义，传统多不断天格吉凶。本模型保留低权重以体现完整性。

### 3.2 数理分映射

| 吉凶 | 分值 |
|---|---|
| 大吉 | 100 |
| 吉 | 85 |
| 半吉 | 60 |
| 凶 | 32 |
| 大凶 | 12 |

### 3.3 修正项

**加分项（每项 +2~+4，累计上限 +10）**
| 条件 | 加分 |
|---|---|
| 人格属「首领数」 | +3 |
| 总格属「财富数」 | +3 |
| 人格/地格属「艺能数」 | +2 |
| 五格中吉数（大吉+吉）≥4 个 | +4 |
| 三才为「大吉」且人格为吉数 | +4 |

> 三类特殊数名单不在此硬编码，统一从 `assets/eighty_one_numbers.json` 的 `tags` 读取（统计见 `references/03` 第五章）。首领数 27 个、财富数 15 个、艺能数 15 个、刚情运 35 个、女用宜慎 6 个。

**扣分项（累计上限 −15）**
| 条件 | 扣分 |
|---|---|
| 人格为凶/大凶 | −10 / −14 |
| 总格为凶/大凶 | −6 / −9 |
| 地格为凶/大凶 | −5 / −8 |
| 三才为凶/大凶 | −8 / −12 |
| 女性且人格或总格属「女用宜慎」数（21,23,28,29,33,39） | −3（仅提示，不宿命化） |

**最终分** = `Σ(数理分×权重) + Σ加分 − Σ扣分`，限定在 `[0,100]`。

### 3.4 等级
| 分数 | 等级 | 评语基调 |
|---|---|---|
| ≥90 | 极佳 | 数理格局俱佳，传统视为上等名 |
| 80–89 | 优秀 | 吉多于凶，格局顺畅 |
| 70–79 | 良好 | 整体平稳，略有小疵 |
| 60–69 | 一般 | 吉凶参半，宜以三才补数理 |
| 50–59 | 平平 | 凶数偏多，宜调整用字笔画 |
| <50 | 欠佳 | 数理格局多阻，建议重新择字 |

> **重要**：分数仅用于**同姓多名字之间的横向比较**（如起名时筛候选字），不可跨姓比较，更不可作为人生判断依据。
> 出现 100 分属正常：五格俱得大吉且三才大吉时，模型会顶到上限，含义是"数理格局无短板"，并非"完美之命"。

## 第四章 多维度解读映射规则

| 维度 | 主要依据 | 次要依据 | 输出要求 |
|---|---|---|---|
| **性格** | 人格五行 + 人格数理 | 三才成功运 | 描述气质倾向（如木主仁、火主礼、土主信、金主义、水主智），结合数理刚柔 |
| **事业** | 人格数理（主）+ 三才成功运 | 总格、外格 | 指出适合的行业气质（文教/实业/金融/技术/艺术），不指定具体职业 |
| **财运** | 总格 + 是否财富数 | 人格、地格 | 讲"聚财方式"（稳积/机遇/技艺），不作暴富承诺 |
| **健康** | 五格中的大凶数、三才凶格 | 五行偏枯 | **只作温和提示**（如"宜注意作息与情绪调养"），禁止断言疾病 |
| **婚姻** | 人格阴阳（奇阳偶阴）+ 女用宜慎数 | 外格、地格 | 讲相处模式与性格匹配，禁止断言"必离婚/克夫" |
| **家庭** | 地格 + 外格 | 天格 | 讲与父母、子女、配偶的亲缘气质 |

### 4.1 五行性格词典（摘要）
- **木**：仁厚、有主见、向上生长；过则固执、易怒。
- **火**：热情、重礼、行动快；过则急躁、张扬。
- **土**：诚信、稳重、能承载；过则保守、迟缓。
- **金**：重义、果断、有原则；过则刚硬、寡情。
- **水**：聪慧、灵活、善变通；过则多虑、漂泊。

### 4.2 数理奇偶与阴阳
人格数为奇 → 阳（外向、主动、刚性）；为偶 → 阴（内敛、包容、柔性）。
传统认为：阳数宜男、阴数宜女，然现代社会不必拘泥，报告中应作中性表述。
