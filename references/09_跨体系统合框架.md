# 09 · 跨体系统合框架（四轴 · 三层权重 · 交叉印证）

> 本文件回答三个问题：**四个体系凭什么放在一起比**、**权重为什么这样定**、
> **怎样才算"印证"而不是"拼凑"**。实现见 `scripts/synthesis.py`，
> 框架说明亦可由 `synthesis.framework()` 直接取出（报告中 `/synthesis` 字段同步输出）。
>
> 定位不变：以下全部是国学文化层面的结构描述，**仅供审美与文化参考，不具备科学预测效力**。

---

## 一、为什么要统合，以及三个必须先避开的误区

字义、五格、五音、梅花、八字各自成篇时，读者面对的是四份**互不引用的判词**：
五格说"总格大吉"，梅花说"体生用耗"，八字说"用神在木"。
它们可以同时为真，也可以彼此矛盾，但**单看任何一份都看不出矛盾在哪**。
统合层要做的不是再造一个更大的分数，而是让"一致"与"相悖"变成可以指出来的结论。

为此先立三条禁忌：

| 误区 | 表现 | 本框架的处理 |
|---|---|---|
| **分数直加** | 把 88.2、89、62.8、87.3 四个数按权重一乘，得一个"命好不好"的总分 | 四项**语义不同**（见 §3.1），合成值只称「统合加权」，不称吉凶总分；报告中恒并列四项原始分 |
| **同源重复计权** | 五格、五音、梅花同出一名，各自 30% 会变成"姓名占 90%" | 显式声明同源冗余，姓名三项合计 66，另在 §3.5 给出等效独立权重约当 45–50 |
| **把一致当验证** | 四个体系都说"金旺"，就当成事实确认 | 一致只记为「印证」（相互不矛盾），不升级为「已验」；相悖记为「张力」，同等呈现 |

## 二、四条共用轴：四个体系如何落在同一坐标系

四体系能放在一起，是因为它们都能被**降到同一个低维空间**里。
每条轴的取法都选"四者都有、且可换算"的那一面：

### 2.1 五行轴（物质—能量刻度）

| 体系 | 落点 | 换算 |
|---|---|---|
| 八字 | 四柱天干地支的五行力量 | `wuxing_stat[*].total` 归一（含藏干加权） |
| 五格 | 五格数理五行 + 三才三字 | 天/人/地/外/总各计 1，三才三字各计 0.5，归一 |
| 五音 | 宫商角徵羽 | 宫土、商金、角木、徵火、羽水，逐字计 1，归一 |
| 梅花 | 卦局五行配比 | `wangshuai.distribution` 归一（用卦满权、互卦半权） |

归一后四者可直接叠在同一张雷达图上（满格 = 占比 40%），
两两求余弦即得"形状相似度"，六对取均值 = **五行共振度**。

### 2.2 刚柔轴（−1 刚 … +1 柔）

| 体系 | 取法 | 方向约定 |
|---|---|---|
| 八字 | `(生助比 − 0.5) × −2` | 身强＝刚（负） |
| 五格 | 人格奇偶 ±0.35 + 总格奇偶 ±0.15 | 奇数（阳）＝刚 |
| 五音 | `(平声数 × 2 − 字数) / 字数` | 平声柔、仄声刚 |
| 梅花 | 体用生克基数 + 体卦阴阳修正 | 体克用＝刚；体卦阳（乾震坎艮）再 −0.15 |

四值加权平均得**刚柔主轴**，极差得**离散度**。
离散 ≥ 0.35 且两侧各有 2 值 = 「分裂」：说明"骨架"与"气韵"不在同一侧——
这是四体系里最常见、也最值得说的一类错位。

### 2.3 时段轴（早 · 中 · 晚）

| 体系 | 早 | 中 | 晚 |
|---|---|---|---|
| 八字 | 年柱（根基） | 月柱 + 日支（环境与自身） | 时柱（晚景） |
| 五格 | 天格 + 地格 | 人格 + 三才 | 总格 + 外格 |
| 梅花 | 本卦 | 互卦 | 变卦 |
| 五音 | 首字（起） | 中字（承） | 尾字（收） |

四者在"早/中/晚"上同构，故可各自成线：命线（柱位生克）、名线（格运卦象）、
合线（体用权重加权）。**三条线不要求同向**——同向则趋势可信度较高，
分途则以合线为主、不强行断语。时辰未详时，晚段以日支代时柱，并在结果中标注
`late_estimated = True`。

### 2.4 数象轴（只报形式，不作吉凶）

干支六十序、数理 1–81、卦数 1–64、五音序 1–5，四种数字系统之间必然出现巧合。
本框架只列出**四类可判定的形式关系**：

- 尾数相同（23 / 33）
- 互为倒序（23 / 32）
- 相差十的倍数
- 尾数互补成十（32 / 38）
- 同余于八（卦数同宫）

**这些一律不进入评分，也不作吉凶解释**，仅在报告中列为「数象（形式层）」。
列它的理由只有一个：让读者看到"巧合本来就会发生"，从而不必把它当成证据。

## 三、三层权重：为什么是 34 / 26 / 22 / 18

### 3.1 先解决一个前提：四项分数不是同一把尺

| 维度 | 分数含义 | 高分意味着 | 低分意味着 |
|---|---|---|---|
| 八字 | **原局流通度**（`balance.score`） | 五行俱全、通关链完整 | 偏枯、有缺有滞 |
| 五格 | 数理顺逆度 | 五格多吉、三才和顺 | 凶数、三才相战 |
| 五音 | 音律顺逆度 | 声调有起伏、声韵不冲 | 拗口、同音相撞 |
| 梅花 | 卦象顺逆度 | 体用得宜、变卦吉 | 体用相耗、变卦转紧 |

四者量纲不同，但都已被各自的引擎映射到 0–100 的百分位，故**可加权，不可直比**。
报告中"四源分数"一栏必须并列原始分，禁止只给合成值。

### 3.2 一层 · 体用（八字 34 ／ 姓名 66）

- **命为体、名为用**：八字定禀赋格局与喜忌基准，姓名是后天呼召与修饰。
- 但**体不过半**，理由有二：
  1. 八字不可改、姓名可择——本技能的输出价值在"可择"的一侧；
  2. 八字精度依赖出生时辰，时辰未详即四柱缺一（见 §3.4）。
- 34 : 66 不是玄学比例，是"可干预性 × 信息独立性"的折中，允许后续按实测调参。

### 3.3 二层 · 名内（五格 26 ／ 梅花 22 ／ 五音 18）

| 维度 | 权重 | 理由 |
|---|---|---|
| 五格 | 26 | 只看笔画，无读音差异、无起卦随机性，**可复核性最强** |
| 梅花 | 22 | 含本/互/变三段，动态信息量最大，但起卦口径（简体笔画）本身是一种约定 |
| 五音 | 18 | 最贴近日常使用（天天被叫），但判据最主观（普通话四声已非中古四声） |

### 3.4 三层 · 互证加权（`w′ = w · (1 + 0.18c)`）

设各维方向分 `d_i = clamp((score_i − 60) / 40, −1, 1)`，
则 `c_i = Σ_{j≠i} w_j · sign(d_i·d_j) / Σ_{j≠i} w_j ∈ [−1, 1]`。

- `c_i > 0`：该维与多数同向 → 升权（最多 ×1.18）
- `c_i < 0`：该维与多数相悖 → 降权（最低 ×0.82）
- 中性分（|d| 很小）不产生方向，故不参与同向计算

**这条只改合成层，原始分与各维结论一律不动**，且报告中同时给出基准分与调整量
（`score_base` / `delta`），任何人可复算。它本质上是集成学习里的置信度加权：
**孤证降权、互证升权**。

> 边界：当四项分数全部同侧时（例如都在 60 以上），`c_i` 全部为 1，
> 调整量趋于 0——这是正确行为，不是失效。真正的分歧通常发生在五行层与刚柔层。

### 3.5 同源冗余的坦白

五格、五音、梅花同源于**同一个名字**，彼此高度相关。若按独立信息量折算，
姓名三项的等效权重约当 **45–50**，其余 16–21 是"同一件事被数了三遍"的冗余。
本框架因此做了两件事：
1. 压低单项权重（26/22/18 而非均分 22/22/22 之后的放大）；
2. 用互证加权让"三个都说同一件事"不再额外加分。

### 3.6 时辰未详时的降权模型

| 模型 | 八字 | 五格 | 梅花 | 五音 |
|---|---|---|---|---|
| 全量（时辰已知） | 34 | 26 | 22 | 18 |
| 降权（时辰未详） | **22** | 28 | 26 | 24 |

四柱缺时柱，日主强弱的误差最大（时柱常是"得地/得势"的关键根），
故八字让出 12 点给三项可确定的姓名维度。两模型各自合计恒为 100。

## 四、五项量化指标

| 指标 | 公式 | 读法 |
|---|---|---|
| **五行共振** | 梅花·八字·五音三源归一向量两两余弦的均值 × 100 | ≥84 三源同气；72–84 大体同调；<72 各有所主 |
| **互证率** | `Σ w_i · max(0, c_i) / Σ w_i` | 高＝分数层方向一致，低＝内部有分歧 |
| **刚柔离散** | `max(gr) − min(gr)` | ≥0.35 且两侧各 2 值＝表里不一 |
| **用神契合** | `50 + 2.2 × Σ(载体权重 × 喜用 +1 / 忌仇 −1.2)` | ≥60 名助命用；≤44 名逆命用；其间两平 |
| **三段斜率** | `合线(晚) − 合线(早)` | ≥+4 后成；≤−4 早强晚守；其间匀速 |

**用神契合的载体权重**：体卦 3、五音每字 2。（五格数理五行另算，不参与跨体系用神契合）
梅花体卦属传统周易五行体系，与八字同根；五音宫商角徵羽亦归五行。

## 五、交叉印证九则

每条规则输出 `{level, title, detail, dims}`，`level ∈ {印证, 张力, 调和}`。
排序恒为 **印证 → 张力 → 调和**，同题去重；张力虽排第二，却是最该读的部分。

| # | 规则 | 判据 | 输出层级 |
|---|---|---|---|
| 1 | 用神契合 | 用神契合分 ≥60 / ≤44 / 其间 | 印证 / 张力 / 调和 |
| 2 | 体卦 ↔ 日主 | 体卦五行与日主关系 比和·生我 / 克我 / 其余 | 印证 / 张力 / 调和 |
| 3 | 变卦 ↔ 原盘 | 变卦吉凶分与原盘流通度是否同高、同低 | 印证 / 调和 / 张力 |
| 4 | 卦命同旺 | 卦局最旺五行 vs 八字最旺五行：同气 / 生我 / 克我 / 其余 | 印证 / 调和 / 张力 |
| 5 | 用卦生助 | 用卦五行与日主关系：比和·生我 / 克我 / 其余 | 印证 / 张力 / 调和 |
| 6 | 末音 ↔ 总格 | 末字五行与总格数理五行：同气 / 相生 / 相克 | 印证 / 调和 / 张力 |
| 7 | 三源共振 | 共振度 ≥84 / 72–84 / <72（梅花·八字·五音） | 印证 / 调和 / 张力 |
| 8 | 卦局缺用神 | 卦局所缺是否正是用神（或正为忌仇） | 缺用神＝张力；去忌＝印证 |
| 9 | 分数极差 | 四维极差 ≤12 且最低 ≥70 / ≥24 | 印证（四维同调）/ 张力（长短悬殊） |

### 判据的边界

- 规则 2、4、5 用「比和 / 生我」为同向，是因为二者都使主体得气；
  「我克」虽属主动，但仍是耗，故归入调和而非印证。
- 规则 8 只查 `lacking`（三源皆无），不查"占比很低"，避免把小概率当缺失。

## 六、统合图的六段读法（`05_统合.svg`）

| 段 | 内容 | 读法 |
|---|---|---|
| 一 · 四源分数与权重 | 四张分数卡 + 三层权重条 + 统合加权 | 先看**四项原始分的语义标签**，再看权重，最后才看合成值 |
| 二 · 五行共振 | 五轴雷达，三源叠图（梅花·八字·五音）+ 三对余弦 | 形状越接近越同气；某一源"鼓出一角"处，即该体系的偏重 |
| 三 · 刚柔对照 | 四条 −1…+1 轴 | 四点聚在一侧＝内外同调；两侧分立＝表里不一 |
| 四 · 三段走势 | 命线 / 名线 / 合线 | 只看合线方向不看单点高低；命名分途时不下强断 |
| 五 · 交叉印证 | ✓ 印证 / ! 张力 / ≈ 调和 | **先读"!"**，再读"✓"；"≈"是各有其理，不必强行统一 |
| 六 · 整体趋势 | 3–4 句，全部由数值驱动 | 与前五段逐项对得上，不对应处即为分析瑕疵 |

## 七、已知局限（不做的事）

1. **不加总成"命好坏"**。合成值只表示"四体系在当前权重下的一致程度与顺逆水平"（五行共振仅取三源），
   不是人生判断，也不与任何外部标准可比。
2. **不做大运流年**。本框架的时段轴是"柱位/卦位/格位"的结构映射，
   不是运程推算；八字只排原盘，不排大运。
3. **不跨姓比较**。分数只在同姓候选名之间可比，跨姓权重会失真。
4. **数象不入评**。同尾、倒序、成十、同余，一律视为形式巧合。
5. **权重可调，但须留痕**。任何权重改动都要同步 `WEIGHTS`、`framework()`、
   本文件与 CHANGELOG，并在 `tests.py` 中锁住"合计恒为 100"与关键样例数值。
6. **一致 ≠ 已验**。三源同向只说明这套体系内部自洽，不构成对现实的预测。
