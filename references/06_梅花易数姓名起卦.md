# 梅花易数姓名起卦与五行旺衰

> 本文件定义"姓名终身卦"的起卦、体用、旺衰判法与解读框架。
> 梅花易数属象数之学，结论以"象"为喻，不作命运断语。

## 一、起卦规则

### 1.1 姓名终身卦（个人）

```
上卦数 = 姓之笔画和        （单姓取该字，复姓取两字之和）
下卦数 = 名之笔画和        （单名取该字，双名取两字之和）
动  爻 = (姓笔画和 + 名笔画和) 除 6 取余，余 0 为第六爻
```

取卦用**先天八卦数**（邵雍先天图）：乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8。
卦数除 8 取余，余 0 为坤（8）。

**计算例（李明华）**：李 7 画 → 7 除 8 余 7 → 艮为上卦；明 8 + 华 14 = 22 画 →
22 除 8 余 6 → 坎为下卦；7 + 22 = 29，29 除 6 余 5 → 第五爻动。
上艮下坎 = **山水蒙**。

### 1.2 机构名卦（公司／团队）

```
前半字笔画和 = 上卦数
后半字笔画和 = 下卦数
总笔画       = 动爻数（除 6 取余）
```

字数分界：双字取一字一卦；三字取 1 | 2+3；四字取 2 | 2。单字机构名无法分判上下卦，
须补字或改用其他方法。

### 1.3 起卦法的边界

- 笔画一律用**康熙字典繁体笔画**（与五格同源），否则卦象会偏移；
- 笔画和相近的名字容易得到同卦（如 23 画与 31 画同余 7），这是本法的固有特性，
  并非计算错误，报告中应说明；
- 姓名终身卦的传统说法是"一名一卦，终身不变"，故本技能**不以查询当时月令定终身**，
  月令只作"当下气候"单列。

## 四、五行旺衰（本技能的重点）

梅花易数断卦重"体卦之气"。本技能分两层判：

### 4.1 卦局配比（定终身格局）

取六个卦位中除体卦自身外的五位，逐一与体卦比较：

| 卦位 | 权重系数 |
|---|---|
| 用卦（本卦中非体之卦） | ×1.0 |
| 上互 | ×0.5 |
| 下互 | ×0.5 |
| 变卦上下卦 | 不计入（另作"结局"判） |

每个卦位的受力权重：

| 关系（从体卦视角） | 权重 |
|---|---|
| 生体（他生我） | +1.5 |
| 比和（同我） | +1.0 |
| 体克（我克他） | +0.3 |
| 泄体（我生他） | −0.8 |
| 克体（他克我） | −1.5 |

```
体卦气势指数 = clamp(55 + Σ权重 × 15, 0, 100)
```

基准取 55 而非 50，是承认"取名多用美字"的常情，使多数名字落在中上区间。
变卦不计入卦气，是因为变卦已单独作为"结局"参与评分，重复计权会双算。

### 4.2 月令旺衰（定当下气候）

以月建定当令五行，判体卦处于旺、相、休、囚、死：

- **旺**：与月令同气，当权得令
- **相**：月令所生，气势方兴
- **休**：生月令者，退气休歇
- **囚**：克月令者，受制被囚
- **死**：月令所克，失令无气

| 月建（节气近似） | 当令五行 |
|---|---|
| 寅（立春后）卯（惊蛰后） | 木 |
| 巳（立夏后）午（芒种后） | 火 |
| 申（立秋后）酉（白露后） | 金 |
| 亥（立冬后）子（大雪后） | 水 |
| 辰（清明后）未（小暑后）戌（寒露后）丑（小寒后） | 土 |

**为何月令不作终身主判**：若以查询当月定终身，同一个名字在不同月份会得出不同结论，
不符合"终身卦"名义。故月令只呈现为"当下气候"，并明确提示"随岁月流转而变"。

### 4.3 五行偏枯提示

- 某五行在六位中出现 ≥3 次 → 判"独旺"，提示"所克者易受牵动，宜留余地"；
- 六位中完全不见某五行 → 判"偏虚"，提示"该方向先天助力较少，可于后天补"。

## 八、解读框架与边界

解读按"根基—过程—结果"三段：

1. **根基（本卦·早年）**：本卦卦义 + 体卦在卦局中的受力，主先天条件；
2. **过程（互卦·中年）**：互卦所示中途气候，主中年所遇；
3. **结果（变卦·晚景）**：变卦与体的关系，主晚境所归。

**禁止事项**：
- 不得把卦象说成"必然发生"之事；
- 不得据卦象断疾病、断寿夭、断婚变；
- 不得推荐"化解之法"（摆件、改名消灾等）；
- 所有输出必须附"国学文化娱乐参考，不构成命运决断"的声明。
