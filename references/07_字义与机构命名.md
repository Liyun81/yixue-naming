# 字义解析与机构命名

## 一、字义解析的三层

一个字进入姓名，其意义分三层看：

| 层 | 内容 | 例（明） |
|---|---|---|
| 本义 | 造字之初所指 | 日月相照，光明 |
| 引申 | 由本义衍生的常用义 | 明白、明智、昭明 |
| 意象 | 在诗文与礼俗中积淀的画面 | 日月并照，无所不烛 |

报告中三栏并列，用户可自取所需。**字义库不臆造**：未收录的字直接标注"字义库未收录，
可查《说文解字》或《康熙字典》"，绝不生造解释。

### 1.1 字义五行 ≠ 数理五行

这是最容易混淆的一点，必须在报告中区分：

| 体系 | 依据 | 用途 |
|---|---|---|
| **字义五行** | 字所指事物的传统归类（林属木、炎属火、坤属土） | 取名用字的意象搭配 |
| **数理五行** | 格数尾数（1、2 木；3、4 火；5、6 土；7、8 金；9、0 水） | 五格、三才的生克判断 |

两者常常不一致（"明"字义属火，而其笔画 8 的尾数属金）。混用会让整套推论失效。

### 1.2 姓氏字义

姓氏字义取"本义 + 姓源"，如"李：木名，李树；古为姓氏大宗，出嬴姓"。
姓是承袭而来，其字义主要供了解源流，不参与吉凶判断。

## 二、起名的用字原则

传统与现代并重，取六条：

1. **音要顺**：避免双声、叠韵、三字同调（详见 05 篇的五音判据）；
2. **形要稳**：笔画繁简相配，避免全为繁杂字（书写与辨识成本）；
3. **义要正**：字义无恶训、无贬义联想，避免生僻到无法录入系统；
4. **不犯讳**：不与长辈名字同字同音；
5. **合性别气质**：非硬性规定，但需与用户期待一致；
6. **忌堆砌**：三字全为"宏大"义（如 伟豪杰），反而失于空泛。

### 2.1 改名思路（供参考，不承诺效果）

改名通常出于三个动机，对应三种思路：

| 动机 | 思路 |
|---|---|
| 读音不顺、常被念错 | 优先换"音"，保住原名的字义脉络 |
| 数理格局有缺 | 在同姓下重挑笔画组合，使三才与人格趋吉 |
| 字义不合期待 | 保留一字，替换另一字，使字义与卦象同向 |

**必须说明**：改名改变的是称呼与自我暗示，不是命运。任何"改名即可转运"的说法，
本技能不予采用。

## 三、机构命名（公司／团队／商号）

个人姓名用五格，机构名没有"姓—名"结构，故改走三条线：

### 3.1 总笔画数理

全名笔画和 → 除以 81 取余（余 0 记 81）→ 查数理吉凶。这是商号命名的传统做法
（旧时招牌讲究"总格得吉数"）。数理只作参考，不能替代商标可注册性、行业适配等实务判断。

### 3.2 五音与响度

商号讲究"叫得响、记得住"：

- 三字全为平声（如"同和堂"）读来平板，缺少顿挫；
- 全为仄声则急促；
- 首选"平仄相间"，且末字宜开口度大、声调上扬或平稳，便于远传。

### 3.3 卦象

前半为上卦、后半为下卦、总数取动爻，判体用与卦气（详见 06 篇）。
商号卦象重点看**用卦对体卦**：体为自身根本，用为市场与外境。
"用生体"利于借势，"体克用"主掌控而费力，"用克体"提示外境压力大。

### 3.4 行业用字建议

| 行业 | 宜用意象 | 忌 |
|---|---|---|
| 科技／智造 | 明、智、创、拓、新、锐、联 | 陈旧、迟滞之字 |
| 商贸／流通 | 通、达、汇、盈、源、聚 | 闭塞、枯竭之字 |
| 文化／教育 | 文、雅、书、墨、教、育 | 轻浮、油滑之字 |
| 医养／餐饮 | 和、安、康、养、味、膳 | 肃杀、寒凉之字 |
| 建筑／地产 | 基、固、宇、城、安、居 | 飘摇、虚浮之字 |

字表仅为传统意象的归纳，**不构成行业分析或商业建议**。

## 四、输出边界

- 字义解析只讲字，不评判"这个名字配不配你"；
- 起名建议给出**方向与候选字**，不宣称"此名必发"；
- 机构命名须提示：商标注册、工商核名、行业规范用语等实务问题需另行核查，
  本技能不涉及；
- 全部结论归入"国学文化娱乐参考"。
