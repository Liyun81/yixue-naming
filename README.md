# 易学姓名学解析

> 基于周易易理与传统姓名学的姓名分析技能：**字义 → 五格 → 五音 → 梅花易数 → 八字原盘 → 跨体系统合** 七段解读，
> 支持个人测名、起名候选比较、公司/团队命名、八字排盘（真太阳时）。
>
> **定位**：国学文化娱乐参考，**仅供审美与文化参考，不具备科学预测效力**，**不构成命运决断**。
> 不可用于健康、婚姻、投资、择业等任何实际决策。

## 三、快速开始

```bash
PY=python          # 换成你的解释器路径亦可
cd 易学姓名学解析

# 1. 完整解析一个姓名（默认含字义 + 五格 + 五音 + 梅花易数）
$PY scripts/cli.py analyze --surname 李 --given 明华 --gender male

# 2. 直接给全名，自动判定单姓 / 复姓
$PY scripts/cli.py analyze --full 欧阳明华

# 3. 起名：多候选横向比较，按综合分排序
$PY scripts/cli.py analyze --surname 王 --candidates "浩然,宇轩,子睿,思远"

# 4. 公司 / 团队 / 商号命名
$PY scripts/cli.py analyze --org "同和堂"

# 5. 八字排盘（真太阳时）：出生时间 + 出生城市；境外出生给 --tz
$PY scripts/cli.py analyze --full 李苏翰 --birth "1990-05-20 14:30" --city 成都
$PY scripts/cli.py analyze --full 李苏翰 --birth "1987-07-15 15:00" --city 上海   # 夏令时年份自动还原
$PY scripts/cli.py analyze --full 李苏翰 --birth "1985-03-15 09:00" --tz -8       # 境外出生

# 6. 只要结构化数据
$PY scripts/cli.py analyze --surname 李 --given 明华 --json
```

最小可用三步：`--surname` + `--given` → 拿到完整报告；或 `--full` 一步到位。

## 五、五维体系与统合

| 维度 | 判据 | 产出 |
|---|---|---|
| **字义** | 本义 → 意象 → 字义五行 | 逐字释义与取名导向（区分姓氏本义与名字用字） |
| **五格** | 康熙繁体笔画 | 天/人/地/外/总 五格 → 81 数理 → 三才 → 六维解读 |
| **五音** | 声母发音部位（喉齿牙舌唇） | 宫商角徵羽、平仄、相邻顺逆生、音律评分 |
| **梅花易数** | **现代简体字规范笔画**：姓和 / 名和 / 总和（繁体输入先转简体） | 本卦·互卦·变卦、体用、六位卦局旺衰、体卦气势指数 |
| **八字原盘** | 出生时间 + 出生地（时区/夏令时还原 → 真太阳时） | 四柱藏干十神、五行力量、日主强弱、喜忌（用神/喜神/忌神/仇神/闲神）、调候、原盘评分 |
| **跨体系统合** | 四维齐备时自动生成 | 四轴投影、三层权重、五行共振、刚柔对照、用神契合、三段走势、交叉印证、统合图 |

报告固定七段：字义 → 五格格局 → 五音与平仄 → 梅花易数终身卦 → 八字原盘（提供出生信息时）→ 跨体系统合 → 综合印象。各段末尾与每张图均附免责声明（仅供审美与文化参考，不具备科学预测效力）。八字为独立维度，不并入姓名综合分。
脚本输出即按此顺序，无需二次整理。

### 维度解读图

每一维度的文字结论之后，紧跟一张水墨风解读图，路径直接印在报告中：

```
　图│五格剖象　output/刘宇鹏/01_五格.svg
```

| 图 | 版式要点 |
|---|---|
| **一 · 五格剖象** | 天/人/地/外/总五枚圆牌，人格居中压太极；格位铺五行元素色环与徽记，底部附五行色标；吉凶以朱砂/赭石/灰墨分色 |
| **二 · 五音律吕** | 宫居中、徵羽角商据四方，十二律刻度环外；姓名逐字音牌 + 平仄谱 + 五项音律分条 |
| **三 · 梅花卦象** | 本卦六爻大书（动爻朱色）、互卦/变卦列右、体用括号、五行旺衰条、起卦三数（标注简体笔画） |
| **四 · 八字原盤** | 真太阳时标注带、四柱命盘（日柱高亮、藏干十神）、五行力量条、强弱三徽、喜忌链、原盘评分 |
| **五 · 五維統合** | 四源分数卡＋三层权重条 → 五行共振雷达（四源叠图）→ 刚柔对照轴 → 三段走势折线（命/名/合）→ 交叉印证清单（✓/!/≈）→ 整体趋势解读；980×1612 |

共用元素：宣纸底与纸纹、双墨框四角鱼尾、楷体竖题、朱砂白文印、图内免责声明。四张维度图 820×1120，
`--png` 可另出同名 PNG；不装任何 Python 图形库——SVG 由 `scripts/dimension_card.py`
纯标准库拼出，PNG 借本机浏览器截图（找不到就保留 SVG）。
`output/` 是运行期目录，不入分发包，随时可删。

### 统合层怎么读（权重与判据）

四体系本不同源，统合层只把它们投影到同一组坐标再比较，不制造新的"总分神话"。

- **四条轴**：五行（木火土金水占比）、刚柔（−1 刚 … +1 柔）、时段（早·中·晚）、
  数象（干支序/数理/卦数/音序，**只报形式呼应，不参与评分**）。
- **三层权重**：体用 八字 34 : 姓名 66 → 名内 五格 26 : 梅花 22 : 五音 18 →
  **互证加权** `w′ = w·(1+0.18c)`（孤证降权、互证升权，只改合成层）。
  时辰未详时八字降为 22，其余三项上调；两种模型各自合计恒为 100。
- **语义提醒**：八字分是「原局流通度」（高＝流通，低＝偏枯），五格/五音/梅花分是
  「该维度的顺逆度」。两者不可直接比大小，合成前统一为百分位。
- **交叉印证**分三层：`✓ 印证`（两维同向）、`! 张力`（相悖，最值得看）、
  `≈ 调和`（各有其理、不成一致）。**"一致"不等于"已验"**，结论仍以行事为准。

详见 `references/09_跨体系统合框架.md`，或在代码里读 `synthesis.framework()`。

### 三条不可违反的规则

1. **字义五行 ≠ 数理五行**。前者按字所指事物归类，后者按格数尾数。两套量纲不得互相代入推论。
2. **分数只在同姓候选名之间可比**。跨姓比较无意义，更不可当人生判断。
3. **缺字不臆造**。字义查不到就标「未收录」；笔画缺字走补录或标注低置信估算。

## 八、边界与限制

- **不输出**「改运」「化解」「消灾」「必然」式表述；不据卦象断疾病、寿夭、婚变；
  不推荐摆件、法事、付费化解。
- 对未成年人只报数理与读音，不作婚姻、财富暗示。
- 机构命名会提示商标注册、工商核名需另行核查。
- **流派差异**（外格单姓单名取 2 还是 1、五音 j/q/x 归角还是舌面、梅花起卦用姓名还是时刻）
  本技能有明确默认值，可用参数切换，报告中注明所采用流派。
- 康熙笔画库与字义库各 2737 字（简体笔画库 2736 字），均为**有限语料**。生僻字需补录，这是设计好的扩展路径。

**统一答复格式**（每条都按此五段，缺项即 `doccheck` FAIL）：

```
#### D02 · 加了 --png 却没生成 PNG？
- 一句话：PNG 借本机浏览器截图，失败保留 SVG 并静默降级。
- 依据：scripts/dimension_card.py 的 to_png() 与 find_browser()。
- 怎么做：确认装了 Edge/Chrome；或用浏览器打开 SVG 打印成 PDF。
- 别这样：不要把「没有 PNG」当成分析失败——SVG 才是主产物。
- 相关：D01、D05
```

高频问题的三条硬答案：

1. **不给出生地不要排八字** → 经度直接改时柱（FAQ A02、B03）。
2. **分数不能跨姓、不能相加、不能当吉凶** → 只比同姓候选、只作维度诊断（FAQ C02、C08）。
3. **图与数据必须对应本次姓名** → 1.6.4 起有归属校验，异常直接报错不静默（FAQ D05）。

新增 FAQ 时按「编号只增不改、五段式不缺项、依据可回溯、一句话 ≤80 字」执行，
再跑 `python scripts/cli.py doccheck` 验收。

## 十一、反馈与迭代

当前版本 **1.7.2**。功能完备性以 `selfcheck` + `doccheck` + `test` 通过为准，
**不代表结论已达学术共识**。实际测试中如遇以下情况，请反馈具体输入与输出：

- 某字笔画与实际康熙字典不符，或简体笔画 / 繁→简映射有误
- 某姓名结构（三字姓、复姓+单名、少数民族姓名）拆分错误
- 报告内容前后矛盾、量纲混用
- 五音 / 卦象判定与所据文献不一致
- 编码、路径、跨平台运行问题

反馈时附上完整命令与输出，便于定位。
